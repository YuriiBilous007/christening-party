# Хрестини Терези

Next.js. `npm install`, `npm run dev` (або `npm run dev -- --port 3002`). Перевірка: `npm run build`.

Свято: 25 жовтня 2026, 14:00 America/Chicago (UTC−05:00), ресторан о 16:00. Дані та календар — `lib/event.ts`. Відлік обчислюється за абсолютним часом незалежно від часового поясу гостя.

Повернуто попередній boho-дизайн: беж і теракота, акварельні сухоцвіти та органічні форми. Секції і тексти відповідають ТЗ для Терези: запрошення, відлік, програма, подарунки, RSVP. Весільний проєкт не змінений. Фото Терези вже додане з кадруванням та частково прикритим обличчям. Для заміни додайте підготовлене фото в `public` і вкажіть шлях у `event.photo`.

RSVP: ім’я, присутність, дорослі, діти, вік кожної дитини (0 = до року). При відмові надсилаються нульові кількості; без дітей — порожній масив віку. Поля прихованих гілок не вимагаються.

Для отримання відповідей і публічного списку використовується Supabase. Створіть проєкт, виконайте `database/setup.sql` у SQL Editor. Додайте `SUPABASE_URL` і `SUPABASE_SERVICE_ROLE_KEY` у `.env.local` та Vercel Environment Variables, потім перезапустіть/перерозгорніть сайт. Ключ доступний лише серверу. RLS закриває прямий доступ anon/authenticated. Formspree більше не використовується; попередні відповіді автоматично не імпортуються.

Публічний список `/api/rsvp` містить тільки підтверджених гостей: ім’я, дорослі, кількість дітей. Вік дітей зберігається приватно. Форма повідомляє про публічність імені. Повторна відповідь з того самого браузера оновлює запис за HttpOnly cookie; інший браузер створить інший запис. Імена не є унікальними. Список оновлюється після RSVP та кожні 30 секунд (до 1000 записів). Без налаштованого сховища — явний попередній перегляд без збереження.

Фото для сайту: `public/tereza-portrait.png`, оброблене вбудованим image_gen із наданого фото. Тепле кадрування, видалена лікарняна табличка, частина обличчя прикрита написом у самому зображенні.
